# u2dm logo

The u2dm logo, rendered from LaTeX to SVG and PNG.

</div>

## Assets

Each build produces four variants, in both SVG and PNG formats, published to
GitHub Pages at `https://u2dm.github.io/logo/<name>`:

| Variant | Description | SVG | PNG |
| --- | --- | --- | --- |
| `logo` | Transparent background | [logo.svg](https://u2dm.github.io/logo/logo.svg) | [logo.png](https://u2dm.github.io/logo/logo.png) |
| `logo-white` | Same as `logo` (for light backgrounds) | [logo-white.svg](https://u2dm.github.io/logo/logo-white.svg) | [logo-white.png](https://u2dm.github.io/logo/logo-white.png) |
| `logo-dark` | White fill (for dark backgrounds) | [logo-dark.svg](https://u2dm.github.io/logo/logo-dark.svg) | [logo-dark.png](https://u2dm.github.io/logo/logo-dark.png) |
| `logo-app` | White rounded square with pride rainbow bands | [logo-app.svg](https://u2dm.github.io/logo/logo-app.svg) | [logo-app.png](https://u2dm.github.io/logo/logo-app.png) |
